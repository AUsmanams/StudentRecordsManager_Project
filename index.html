PROJECT OVERVIEW

A practical demonstration of Java OOP

This project combines several Java programming concepts into one working application rather than demonstrating each concept separately.

01

Student Management

The application stores and manages records for regular and part-time students.

02

Object-Oriented Design

The system uses inheritance, method overriding, objects, classes and encapsulation.

03

Persistent Records

Student records can be serialized to a file and restored through deserialization.

FIVE REQUIRED ELEMENTS

Requirements demonstrated in the application

Each required element from the mini-project specification is implemented in the application.

01

Inheritance

The application contains a Person superclass with Student and PartTimeStudent subclasses. Methods are overridden where appropriate.

02

Array & Loop

A Person array stores student objects and a loop processes the stored records.

03

Custom Exception

InvalidStudentException is used to validate student information and handle invalid ages.

04

Serialization

Student records are saved to students.dat and can later be restored through deserialization.

05

Java AWT GUI

AWT components provide the graphical interface for adding, displaying, saving and loading student records.
