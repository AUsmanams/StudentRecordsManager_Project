STUDENT RECORDS MANAGER
=======================

Integrated Object-Oriented Application

Abubakar Aliyu

Programme:

Project Description
-------------------
Student Records Manager is a Java-based application developed to
manage regular and part-time student records. The application
demonstrates important Object-Oriented Programming concepts,
exception handling, arrays and loops, serialization and a simple
AWT graphical user interface.

Requirements Demonstrated
-------------------------

1. INHERITANCE
--------------
Superclass:
Person

Subclasses:
Student
PartTimeStudent

Both Student and PartTimeStudent inherit from Person.

The displayInfo() method is overridden in the subclasses.


2. ARRAY AND LOOP
-----------------
An array of Person objects is used in StudentManager.java:

Person[] people

A for loop is used to process and display the student records.


3. CUSTOM EXCEPTION
-------------------
Custom exception class:

InvalidStudentException

The exception is thrown when an invalid student age is entered.

The exception is caught using try-catch in the application.


4. SERIALIZATION AND DESERIALIZATION
-------------------------------------
Student records can be saved to a file using serialization.

File:
students.dat

The saveToFile() method performs serialization.

The loadFromFile() method performs deserialization and restores
the saved student records.


5. AWT GUI
----------
The graphical user interface is implemented in:

StudentRecordsGUI.java

The application uses Java AWT components including:

- Frame
- Label
- TextField
- Choice
- Button
- TextArea
- ActionListener

The GUI allows the user to:

- Add regular students
- Add part-time students
- Display student records
- Save records
- Load records
- Clear input fields


PROJECT FILES
-------------

Person.java
    Superclass containing common person information.

Student.java
    Represents a regular student.

PartTimeStudent.java
    Represents a part-time student.

InvalidStudentException.java
    Custom exception used for invalid student information.

StudentManager.java
    Manages the student array, loop processing, exceptions,
    serialization and deserialization.

StudentRecordsGUI.java
    Provides the AWT graphical user interface.

README.txt
    Provides documentation and identifies the five required
    elements of the mini-project.

students.dat
    Stores serialized student records generated by the application.


HOW TO RUN
----------

1. Open the project in Visual Studio Code or another Java IDE.

2. Make sure Java is installed.

3. Run:

   StudentRecordsGUI.java

4. Enter the student information.

5. Select either Regular Student or Part-Time Student.

6. Click Add Student.

7. Use Display Records to view the records.

8. Use Save Records to save the records to students.dat.

9. Use Load Records to restore saved records.
